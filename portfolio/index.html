The process

From user stories to a working deployment.

I used an iterative, feature-by-feature approach: understand the user need, build the smallest complete flow, test it in the browser, and refine the interface before moving forward.

  1. 01

    Plan the experience

    I translated the assignment’s user stories into clear screens and routes, then separated responsibilities across the home, movies, cart, and accounts apps.

  2. 02

    Build the foundation

    I created Django models, views, URLs, and templates, using reusable base layouts so navigation and visual patterns stayed consistent.

  3. 03

    Connect each journey

    I linked search to movie details, movie details to the cart, checkout to saved orders, and authenticated accounts to review management.

  4. 04

    Test, debug, and deploy

    I worked through questions by isolating one route or feature at a time, checking Django documentation and course examples, and validating the completed flow on PythonAnywhere.
